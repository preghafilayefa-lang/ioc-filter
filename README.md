# IOC Malware Filter

Check your IOCs against VirusTotal and automatically filter out clean ones.

## How to Use

1. Get your free VirusTotal API key at https://www.virustotal.com
2. Upload your Excel file
3. Paste API key
4. Click "Check IOCs & Filter"
5. Download cleaned file

## Features

- ✅ Checks against VirusTotal (90+ vendors)
- ✅ Automatically removes clean IOCs
- ✅ Works on any network
- ✅ Free to use
